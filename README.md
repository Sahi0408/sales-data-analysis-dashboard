# Sales Data Analysis Dashboard

## Overview
This project focuses on analyzing sales data using SQL and Power BI.
The dashboard helps identify sales trends, top-performing products,
and regional business performance.

## Tools Used
- SQL
- Microsoft Excel
- Power BI

## Features
- Sales Trend Analysis
- Profit Analysis
- Region-wise Insights
- Interactive Dashboard
- Business KPI Visualization

## Key Insights
- Electronics category generated highest revenue.
- North region showed strong sales performance.
- Monthly sales trend helped identify business growth.
